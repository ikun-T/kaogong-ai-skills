# 资料分析与数量关系

本文件为项目原创教学整理与原创例题，公式来自普通数学定义，不宣称某位讲师独创。个人方法归因另查 `methods.json`。

## 先识别，再计算

把每个取数标成“主体—时期—指标—单位”。确认同比与环比、累计与当期、金额与数量。若分子和分母口径不同，不先做除法。先把设问翻译成目标量：基期、增长量、增长率、比重、均值、倍数或差值。

现期 A，基期 B，增长率 r（20% 用 0.2）：

- `A = B(1+r)`；`B = A/(1+r)`；增长量 `Δ = A-B = Ar/(1+r)`。
- 多年增长因子相乘。两期 `R = r1+r2+r1*r2`；年均复合增长率 `r = (A/B)^(1/n)-1`。n 为间隔数，不是列出的年份数量。
- 现期比重 `p=A/T`；分子增速 a、分母增速 b，则基期比重 `p0=p*(1+b)/(1+a)`；比重差 `p-p0=p*(a-b)/(1+a)`。
- 平均数／比值增长率 `g=(1+a)/(1+b)-1=(a-b)/(1+b)`。这里分母是 `1+b`，与比重差不同。
- 混合增长率按基期量加权：`r=(B1*r1+B2*r2)/(B1+B2)`。直接用现期量加权通常错误。
- 拉动增长率为部分增长量除以总体基期量；增长贡献率为部分增长量除以总体增长量。总体增长量接近0时，贡献率可能极大；为0时无定义。

比重从20%到25%是提高5个百分点，增幅25%。A是B的3倍，对应比B多2倍。“下降20%后再上升20%”回不到原值。

## 速算的可用条件

先写正确精确式，再选近似或比较。只有在误差不会改变选项判断时才截位；“差大截两位，差小截三位”是经验启发，不能替代误差检查。

正数分数 `n/d`：若 `n∈[nl,nu]`、`d∈[dl,du]` 且 `dl>0`，结果在 `[nl/du,nu/dl]`。区间仍跨多个选项就加精度。比较两个正分数可交叉相乘；若有负分母先统一符号。

当 r≈1/n 时，`Δ≈A/(n+1)`，但 r 不精确等于 1/n 就不是等式；负增长不可直接套同一个正增长口诀。`A/(1+r)≈A(1-r)` 的绝对误差为 `A*r²/(1+r)`（A≥0、r>-1），增速不够小或选项太近时回到精算。

原创例：A=120，r=20%。基期100，增长量20，不能用120×20%=24。用近似 `120(1-0.2)=96` 误差4，选项99、100、101、102时该近似无效。

## 数量关系的建模选择

| 情境 | 优先动作 | 易失效之处 |
|---|---|---|
| 工程 | 统一工作总量，效率相加，分阶段列式 | 中途停工、效率变化不可全程合并 |
| 行程 | 画时间线，统一速度与时间单位 | 追及与相遇方向不同；平均速度不能机械取算术平均 |
| 比例 | 明确同一总体与变化前后关系，必要时赋值 | 赋值会丢失绝对量约束时不可用 |
| 排列组合 | 先决定有序／无序、能否重复、限制位置 | 独立阶段乘法与互斥分类加法不要混淆 |
| 概率 | 建立等可能样本空间或条件概率 | 把“独立”和“互斥”当一回事 |
| 容斥 | 画集合，确认是“恰好”还是“至少” | 三集合交集系数错误 |
| 极值与抽屉 | 构造最坏情形，再加一 | 平均分配不是保证条件 |
| 代入排除 | 先满足整数、范围、奇偶等必要条件，再核对全题 | 局部吻合不能证明全局正确 |

原创工程题：甲独做6天，乙独做12天，合作2天完成1/2，剩余乙独做6天，总共8天。若乙后半段效率翻倍，最后阶段改为3天，总共5天，不能延用8天。

## 错题复盘

记录最早错点与证据：取错年／列错分母／单位不一／百分数与百分点混淆／忽略符号／近似越界／算术错误。先要求学习者复述目标量，再做一道仅改变关键条件的变式；不要把所有错误都解释成“计算慢”。
