# 申论与结构化面试

本文件是原创训练设计，不是官方评分细则，也不冒充讲师课程。具体个人方法另查来源卡。

## 申论：材料—要点—答案

先列题目约束：任务动词、身份、对象、材料范围、字数与文种要求。给材料编号 M1、M2…；将候选要点对应到具体材料段，区分事实、原因、影响和对策。

| 工作表字段 | 用途 |
|---|---|
| 材料位置与事实概括 | 保留可核对依据，避免凭空写常识 |
| 对应题目任务 | 同一材料被两题引用时，防止答非所问 |
| 归并后的要点 | 合并同义内容，保留对象、动作、结果 |
| 成稿表达 | 在字数内将材料事实抽象成清晰要点 |
| 未确定之处 | 明确推断与材料明说的区别 |

概括题优先准确和覆盖；分析题按具体任务说明对象、关系和结论；对策题检查主体、动作、对象、实施条件；应用文按情境、受众与功能组织，格式服从题目和文种，而非给所有文种硬套落款。大作文从题意与材料形成论点，段落提供论证而非口号堆砌。

原创微材料：M1社区老人因不熟悉线上预约反复到窗口；M2志愿者每周一次指导，但部分老人无法记住步骤；M3服务站计划试行电话预约。若题目要求“概括现存问题”，可写部分老人仍未掌握预约步骤、现有指导效果有限；不能推断指导缺乏持续性，也不能写“已经全面推行电话预约”——M3只是计划。若题目要求提出建议，可把电话预约表述为待落实的渠道，并补充可执行的辅助措施，但明确这是建议。

批改时先找漏点、失真和越界，再处理归并、顺序与语言。采用“材料依据→当前问题→建议改句”。可给自定义训练量表，如材料忠实度、覆盖度、组织、语言，每项说明标准；不得假称阅卷人会精确给多少分。字数计算方法需说明（是否含标点），实际限制遵循考试要求。

## 面试：题设约束—动作—反馈

先识别角色、权限、目标、有关人员、资源、时限及正在发生的问题。按情境组织真实可执行动作：先处理眼前问题，再了解信息与协同，最后确认结果。综合分析题分析原因和影响，提出有针对性的行动；不强迫每题套一个相同开头和结尾。

人际沟通要回应对方具体顾虑；组织活动交代对象、任务分工、资源和效果检查；应急处置先处理即时危险与基本服务，再查明和沟通。具体法律权限或程序若影响答案，应检索现行权威规定；不要编造“必须处罚”“立即封停”等权限。

原创情境：预约系统故障，大厅聚集办事群众，你是窗口工作人员。可先解释当前故障、引导分流并上报技术支持；根据本单位允许的预案登记需求、安排人工办理或回访，关注有紧急需求的人；恢复后核对遗漏并通知。不能无依据承诺当天办结全部事项或擅自改变法定办理条件。

练习可采用：给题→等学习者作答→指出最有价值的一点与最需改的一点→追问一个情境变化→复答。检查是否切题、具体、可行、权限恰当、表达有顺序。只有文字输入时只评价文字逻辑与内容，不能声称已观察声音、仪态或临场表现。评价内容和表现，不根据身份特征推断适岗能力。

## 共通边界

教学者的“模板”“高分答案”只能作为待验证的练习材料。不要伪造基层经历、调查数据、名言出处或政策文件来润色答案。没有官方参考答案时承认可以存在多种合理组织方式。
