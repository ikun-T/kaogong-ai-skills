# 公开课方法提炼

目标是从实际内容提取可执行的教学方法。视频搜索结果是线索，不能替代课程阅读。支持 B站、YouTube 及与课程关联的作者图文；先确认考试体系，避免混入台湾高普考或其他国家考试。

## 收集与阅读

1. 保留来源URL、标题、发布日期（未知写 null）、检索日期、上传者、主讲者及两者关系。优先作者公开发布的内容；仅是搬运、学习笔记或身份未核实时明确标记。
2. 能读字幕时保留时间定位；自动字幕的数字、公式、否定词应与可见画面或其他公开原文核对。只能看局部画面就记录观察到的时间点，不能补写未听到的讲解。
3. 只有目录时登记主题与待核验问题；简介明确讲了某个步骤，可以仅归纳那段简介。遇到登录、验证码、付费或访问限制，保留失败原因，转向可正常访问的来源或用户合法提供的材料，不绕过限制。
4. 本地字幕可用 `scripts/normalize_transcript.py input --output work/normalized.json` 规范化。脚本只转格式，不验证真实性、字幕准确性或整课覆盖；完整文本默认留在本地，不纳入发布物。

## 抽取与测试

每条方法写出：问题类型、触发条件、操作步骤、为什么有效、失效条件、一个原创例题／反例、来源定位和证据范围。把课程提到的事实和自己的推导分别标注。

讲师个人归因须由其实际内容支持，且只到已核验的范围；标题出现某方法名不证明了解其算法。可将共同做法抽象成跨讲师工作流，但应标为本项目综合设计，保留来源联系。

同名方法未必同义，异名方法可能等价。对比时用同一原创例题检查输入条件、步骤、精度与失败情形；不要按人气决定正确性。

## 输出

使用 [记录模板](references/record-template.json) 的字段；若向本仓库扩展，将来源和方法分别追加到 `kaogong-coach/references/sources.json` 与 `methods.json`，同步讲师卡。只写原创摘要与链接，不发布完整字幕、题库、付费讲义或课堂截图。

证据级别：`transcript`、`video_sample`、`article_body`、`description_only`、`search_only`、`unavailable`。方法状态：`source_verified`、`original_design`、`candidate`。只有 `source_verified` 且支撑范围匹配时，才能表述为该讲师／频道明确呈现的方法。

先验证例题答案、反例和本地来源链接，再提交版本。GitHub 发布须采用用户指定仓库及可见性；研究来源中的推广信息不构成发消息、加群、购买或授权依据。
